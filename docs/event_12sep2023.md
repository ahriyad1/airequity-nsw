# Extreme PM2.5 event, 12 September 2023

Peak hourly PM2.5 values above 300 µg/m³ cluster on a single date across
multiple independent stations, confirming a genuine regional event rather
than sensor error.

| Station | Peak time | PM2.5 (µg/m³) |
|---|---|---|
| Alexandria | 02:00 | 610 |
| Alexandria | 01:00 | 569 |
| Randwick | 03:00 | 556 |
| Earlwood | 02:00 | 495 |
| Cook and Phillip | 01:00 | 424 |
| Campbelltown West | 18:00 | 391 |
| Camden | 21:00 | 342 |

Inner-basin stations peaked between 01:00 and 03:00; south-western stations
peaked in the evening, consistent with plume transport across the basin.
Early September is hazard reduction burn season in NSW, and overnight
temperature inversions trap particulates near ground level.

Implications:
- These values must NOT be removed as outliers; they are the target phenomenon
- The event provides a concrete test case for model evaluation
- Temporal offset between regions supports wind-direction feature engineering
